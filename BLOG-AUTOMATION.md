# Daily Blog Publishing

The project now supports static blog pages. For unattended live publishing, connect the production site to a GitHub repository or CMS API. The scheduled ChatGPT task researches two primary-source topics daily; when a publishing connection is available it can update the blog, otherwise it returns ready-to-publish content.

Editorial rules:
- Use primary sources such as WHO, FDA, MHRA, EU Commission, official manufacturers and peer-reviewed papers.
- Write original Persian analysis; do not copy source text.
- Add publication date, reading time, category, cover image and source links.
- Avoid unverified claims, medical diagnosis or promotional exaggeration.
